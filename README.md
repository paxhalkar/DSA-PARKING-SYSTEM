# Mall Parking Management System

A menu-driven parking management application developed in **C** by a team of two classmates as a first-year engineering project. It uses **structures and arrays** to manage vehicle records and parking slots.

The system supports vehicle registration, parking-slot allocation, vehicle search, vehicle exit, and revenue reporting. It demonstrates basic C programming concepts, including functions, loops, conditionals, and data organization.

**Built with:** C, Turbo C/Turbo C++  
**Project type:** Beginner console application
