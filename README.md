DSA-PARKING-SYSTEM

Mall Parking Management System in C

The Mall Parking Management System is a first-year engineering project developed in C by a team of two classmates to demonstrate the practical application of Data Structures and Algorithms (DSA). The project is designed to manage vehicle parking efficiently through a menu-driven, console-based interface using Turbo C/Turbo C++.

Features

Vehicle Registration: Register vehicles with unique IDs, vehicle numbers, vehicle types, and service categories.
Parking Slot Management: Manage 20 parking slots, display availability, and allow users to select an available slot.
Vehicle Exit: Process vehicle exits and automatically release occupied parking slots.
Vehicle Search: Search for vehicle records and check their parking status.
Vehicle Details: Display registered vehicle information, including vehicle type, slot number, parking fee, and status.
Parking Fee Calculation: Charge ₹20 for two-wheelers and ₹40 for four-wheelers, with fee exemptions for ambulance, defence, and government vehicles.
Owner Report: Display total registered vehicles, vehicles currently parked, available slots, vehicle category counts, and total recorded parking fees.
Input Validation: Handle invalid menu choices, vehicle types, service categories, slot numbers, and duplicate active vehicle registrations.
Technologies and Concepts Used

Programming Language: C
Compiler Environment: Turbo C/Turbo C++
Data Structures: Structures and arrays
DSA Concepts: Linear searching, sequential traversal, slot allocation, and record management
Libraries: "stdio.h", "conio.h", "string.h", and "ctype.h"
Project Objective

The main objective is to apply fundamental C programming and DSA concepts to a practical parking management problem. This project provides hands-on experience in data storage, searching, input validation, resource allocation, and report generation through a simple console-based application.
